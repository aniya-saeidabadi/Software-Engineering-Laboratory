# بازی مار (Snake Game)

این پروژه برای درس آزمایشگاه مهندسی نرم‌افزار و با زبان پایتون نوشته شده است. بازی از نمونه‌های کلاسیک Snake الهام گرفته و هدف آن کنترل مار، جمع‌آوری میوه‌ها و به دست آوردن بیشترین امتیاز ممکن است.

## پیش‌نیازها

- نصب Python نسخه 3.9 یا بالاتر
- نصب کتابخانه Pygame

## نصب و اجرای بازی

ابتدا ترمینال را در پوشه پروژه باز کنید و دستور زیر را اجرا کنید:

```bash
python -m pip install -r requirements.txt
```

سپس بازی را با دستور زیر اجرا کنید:

```bash
python main.py
```

## روش بازی

1. برای شروع، روی دکمه `START` کلیک کنید.
2. مار پس از شروع به‌صورت خودکار حرکت می‌کند.
3. با کلیدهای جهت‌دار صفحه‌کلید مسیر حرکت مار را تغییر دهید. کلیدهای W، A، S و D نیز قابل استفاده هستند.
4. با خوردن میوه، مار یک خانه رشد می‌کند و امتیاز همان میوه به امتیاز کل اضافه می‌شود.
5. برخورد مار با دیواره یا بدن خودش باعث پایان بازی می‌شود.
6. برای شروع دوباره، روی دکمه `START AGAIN` کلیک کنید.

## توضیح بخش‌های برنامه

- **مدیریت رویدادها:** دریافت کلیک ماوس و فشردن کلیدهای صفحه‌کلید با استفاده از حلقه رویدادهای Pygame انجام می‌شود.
- **حرکت مار:** موقعیت سر مار در هر نوبت با توجه به جهت فعلی تغییر می‌کند. اگر بازیکن جهت تازه‌ای انتخاب نکند، جهت قبلی حفظ می‌شود.
- **رشد مار و امتیازدهی:** پس از رسیدن سر مار به محل میوه، آن میوه از صفحه حذف می‌شود، طول مار افزایش پیدا می‌کند و امتیاز مربوط به میوه به امتیاز کل اضافه می‌شود.
- **بررسی برخورد:** پیش از ثبت حرکت جدید، برخورد با محدوده صفحه و بخش‌های بدن مار بررسی می‌شود.
- **شروع مجدد:** با انتخاب دکمه شروع دوباره، وضعیت مار، جهت حرکت، میوه و امتیاز به حالت اولیه برمی‌گردد.
